# Product UI icons

These individually vendored regular-weight SVGs come from the official Phosphor Icons core repository, `assets/regular/`, at commit `2b75f3ad12b420c9504ef05df8d2564a28f8500e`. They are used by the approved Hirearchy Software screens. The upstream MIT license is included in this directory.

Upstream source: https://github.com/phosphor-icons/core/tree/2b75f3ad12b420c9504ef05df8d2564a28f8500e/assets/regular
`SHA256SUMS` records the vendored SVG and license hashes.

No icon package or runtime dependency was added. The SVGs use `currentColor`; when used through `<img>`, set a suitable foreground with a CSS filter on dark surfaces or keep the icon on a light surface.
